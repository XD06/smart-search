# 垂直社区与口碑验证速查表（Tier 3 定向搜索用）

搜索真实用户体验、避坑槽点、长期稳定性时，**必须根据问题所属的具体领域，选择该领域真正的“行家/重度用户”聚集的社区**。
- ❌ 错误做法：不管什么问题都只去单一社区（如只搜 Reddit 或只搜知乎），或者在泛娱乐平台搜硬核专业问题。
- ✅ 正确做法：按领域匹配 2 个以上不同视角的垂直社区交叉验证。

## 三、社区定向检索四大铁律

1. **看差评与追评，不看高赞吹捧**：在 G2、Trustpilot、Steam、京东/什么值得买等平台，直接切入 **2~3 星中差评** 或 **使用数月后的追评**，那里才有真实的边界条件与缺陷。
2. **区分“利益相关”**：警惕正文中带有邀请码（Referral Code）、返利短链、群号引流的帖子，一律按推广软文降权处理。
3. **中外社区交叉验证**：
   - 国际产品（如 Claude、海外 SaaS、全球发售硬件）→ **国际社区（Reddit / HN）看功能深度 + 中文社区（Linux DO / V2EX / Chiphell）看国内网络环境、支付方式与售后差异**。
   - 本土产品（如国产大模型、国内车企、国内金融产品）→ **优先中文垂直社区 + 投诉平台（黑猫/车质网）验证**。
4. **社区只管“体验与口碑”，不管“事实存否”**：社区说“某功能上线了/某政策改了”，只能作为线索，必须回到该领域的 **Tier 1 官方一手网站** 核实。
